# notion-discord-notifier
# Notion ⇄ Discord 自動通知システム (GAS連携)

Google Apps Script (GAS) を利用して、Notion上の**議事録更新**、**タスクの新規・追加更新**、および**本日期限タスクのリマインド**をDiscordへ完全自動通知するシステムです。外部の有料サービスを使用せず、すべて無料で永続運用できます。

---

## 主な機能

### 1. Notion更新自動通知（5分周期）
* **議事録（通常ページ形式）**: 指定した議事録ページの本文や箇条書きが編集された際、ページのタイトルとリンクをDiscordに自動投稿します。
* **タスク（データベース形式）**: タスクデータベースに新規タスクが追加・更新された際、タスク名と直リンクをDiscordに自動投稿します。

### 2. 本日期限タスクの自動リマインド（毎日朝）
* タスクデータベースの「期限」プロパティをチェックし、**提出期限が今日（実行日）のタスク**を一覧抽出し、毎朝決まった時間（例: 朝8:00〜9:00）にDiscordへ赤枠で注意喚起投稿します。

---

## システム構成・必要なもの

* **Notion**: アカウント ＆ コネクト（内部インテグレーション）
* **Discord**: サーバー ＆ チャンネル用 Webhook URL
* **Google Apps Script (GAS)**: 無料Googleアカウント

---

## セットアップ手順

### Step 1: Notion側の設定
1. [Notion インテグレーション管理画面](https://www.notion.com/my-integrations) にアクセスし、「＋ 新規コネクト」を作成します。
   * タイプ: **アクセストークン**
   * 名前: 任意（例: `Discord連携`）
2. 発行された **アクセストークン（`ntn_...` または `secret_...`）** をコピーします。
3. 対象の **「タスクデータベース」** および **「議事録ページ」** をNotion上で開き、画面右上の `...` ＞ `接続（Connections）` から作成したコネクト（`Discord連携`）を追加します。
4. それぞれのページURLから **32桁のID（英数字のみ）** を抽出して保存します。
   * タスクDB ID例: `dd66cc5c9bcd83fa9e2d81847fe146ba`
   * 議事録ページ ID例: `3ab6cc5c9bcd80ee851eff7238b6f186`

### Step 2: Discord側の設定
1. 通知飛ばしたいDiscordチャンネルの `チャンネルの編集（歯車マーク）` を開きます。
2. `連携サービス` ＞ `ウェブフック` ＞ `新しいウェブフック` を作成します。
3. **ウェブフック URL** をコピーします。

### Step 3: GAS（Google Apps Script）の設定
1. [Google Apps Script](https://script.google.com/) で新規プロジェクトを作成します。
2. 画面左側の ⚙ `プロジェクトの設定` を開き、ページ下部の `スクリプト プロパティ` に以下4つを登録します。

| プロパティ名 | 設定する値 |
| :--- | :--- |
| `NOTION_API_KEY` | Notionのアクセストークン |
| `TASK_DB_ID` | タスクデータベースの32桁ID |
| `MINUTES_DB_ID` | 議事録ページの32桁ID |
| `DISCORD_WEBHOOK_URL` | DiscordのWebhook URL |

3. エディタ画面（`コード.gs`）に後述の「本番用ソースコード」を全貼り付けして保存（フロッピーマーク）します。

---

## トリガー（自動実行）の設定

GAS画面左側の  `トリガー` から以下の2つのトリガーを追加します。

1. **更新通知用トリガー**
   * 実行する関数: `checkNotionUpdates`
   * イベントの源: `時間主導型`
   * 時間の間隔型トリガー: `分ベースのタイマー` ＞ `5分おき`

2. **本日期限リマインド用トリガー**
   * 実行する関数: `checkTaskDeadlines`
   * イベントの源: `時間主導型`
   * 時間の間隔型トリガー: `日付ベースのタイマー` ＞ `午前8時〜9時`
